Lista de tests — Pre-merge a main

  SEGURIDAD

  S-01 — Escaping en pantalla de Cola
  - Ir a la pantalla de Cola en el admin
  - Buscar un envío que tenga caracteres como <script>alert(1)</script> en algún campo
  - Verificar que se muestra el texto literal, no ejecuta el script

  RESULTADO: directamente no permite agregar etiqueta script, es decir si intento mandar un script mediante el form, no queda guardado, se omite. 

  S-02 — Escaping en lista de Envíos (campos de selección múltiple)
  - Crear un formulario con un campo checkbox o multi-select
  - Enviar con valores que contengan <b>bold</b> o "quotes"
  - Verificar que en la pantalla de Envíos se escapa correctamente

  RESULTADO: se escapa correctamente

  S-03 — Saneado de inputs en el endpoint
  - Hacer un POST al endpoint /akashic-forms/v1/sync con un campo conteniendo <script>alert(1)</script> o SQL como ';
  DROP TABLE--
  - Verificar que el valor guardado en BD está saneado (sin el script/SQL)

  RESULTADO: correcto, se escapan las etiquetas, se guarda solo texto plano

  S-04 — Solo se aceptan campos declarados
  - Enviar al endpoint un campo extra que no existe en el formulario (ej. campo_inventado: "valor")
  - Verificar que ese campo NO aparece en el envío guardado

RESULTADO: pasado, se ignora el campo que no está declarado. 


  S-05 — Honeypot

  - Verificar que el envío es rechazado
  - Enviar normalmente (honeypot vacío) y verificar que pasa

  RESULTADO: PASADO
